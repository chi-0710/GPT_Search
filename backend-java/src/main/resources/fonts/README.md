# Chinese report font

NotoSansSC.ttf is the unmodified Noto Sans SC variable TrueType font downloaded
from https://github.com/google/fonts/tree/main/ofl/notosanssc on 2026-10-28.
Upstream filename: NotoSansSC[wght].ttf. The bundled OFL.txt contains its license.
The font is packaged locally; report rendering does not download fonts at runtime.

Some extracted PDF characters use Unicode compatibility radicals. Text extraction
tests apply NFKC normalization before comparing semantic Chinese content.
