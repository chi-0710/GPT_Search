## 清单维护

`migration-inventory.json` 从源码静态提取，不读取 `.env`，不代表已迁移。
运行 `python scripts/java_migration_inventory.py --check` 检查是否遗漏新增入口。
Python 脚本仅在迁移开发阶段使用，不属于最终 Java 运行依赖。

`scripts/test_java_migration.ps1` 创建独立网络和临时 PostgreSQL，使用原 Alembic 完整初始化写测试数据库，
在容器中执行 Maven verify，最终清理该脚本创建的容器和网络，不访问应用库。
测试仍使用 Python 初始化对照结构；这不是最终 Flyway 部署。

`JAVA_WRITES_ENABLED=false`、`JAVA_DB_READ_ONLY=true` 为默认设置。
写接口测试显式启用写入并仅连接隔离库；当前 Compose 未开放这些开关。
禁止将“写入功能已测试”理解为允许两套服务同时写入应用数据库。

## 研究节点与运行边界批次

- ResearchNodes 将来源收集器与实际模型操作连接到编译图，状态仅保存可序列化业务数据；运行时依赖保留在闭包中。
- 规划解析验证标题/章节；章节审阅有限重试；事实核查接收证据快照，并先返修章节再重新写作。
- 缺少章节证据与网络/模型异常使用不同错误类型；仅前者可标记章节不足，全部不足时禁止发布。
- HumanReviewChannel 绑定运行 ID 和审核轮次，仅精确 `no` 作为接受标记；取消连接会取消审核等待。
- SpringResearchModel 对接显式配置的 fast/smart/strategic 客户端，记录每次调用用量；UsageLedger 对未知费用保留 null/unknown，检索及图片费用不假设为零。
- 实际 HTTP/WebSocket 装配、完整配置透传、真实图片/导出、供应商全集和 Flyway 仍是未完成项；本批不切换运行服务。
- 本批隔离 Maven verify：89 项测试全部通过，无失败、错误或跳过；含 17 项真实 PostgreSQL 测试。真实研究额度仍未使用。
